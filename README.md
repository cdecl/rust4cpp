## 1. 두 언어의 성격 차이
* **C++:** 개발자에게 폭넓은 제어권을 부여하고 규칙 준수를 요구 (알아서 조심).
* **Rust:** 소유권·대여·타입 시스템을 통해 메모리 및 동시성 안전성을 컴파일 타임에 강제 (대신 막아줌).
* 안전한 Rust 코드에서는 데이터 경합과 댕글링 참조가 원천 방지됩니다.

## 2. 개발 환경: CMake 대신 Cargo
* **`rustup`**: 툴체인 및 크로스 컴파일 타겟 관리.
* **`cargo`**: 빌드 시스템, 패키지 관리자, 테스트 러너 통합 (`Cargo.toml` 하나로 관리).
* **`cargo check`**: 링크를 생략하고 타입 및 소유권 검사만 빠르게 수행 (개발 루프의 핵심).

## 3. 변수, 함수, 그리고 값이 되는 문장
* **가변성:** 기본 불변(`let`), 변경이 필요할 때만 명시적 가변(`let mut`).
* **섀도잉(Shadowing):** 같은 스코프 내에서 `let`으로 재선언하여 타입 변경 및 불변성 잠금 가능.
* **표현식 지향:** `if`, `match`, `{}` 블록 모두 값을 반환하는 표현식(삼항연산자가 불필요).
* **함수:** `fn name(arg: Type) -> RetType { expr }` (마지막 줄에 세미콜론이 없어야 반환값).

## 4. 타입과 컬렉션
* **정수/부동소수점:** `i32`, `u64`, `f64` 등 고정 크기 타입 (`i32`가 기본).
* **문자열:** `String`(힙 소유, `std::string` 대응)과 `&str`(불변 뷰, `std::string_view` 대응).
* **캐스팅:** 암묵적 변환 없음. `as` (강제 비트 변환), `From`/`Into` (안전한 변환), `TryFrom` (실패 가능 변환) 명시.
* **컬렉션:** `[T; N]`(배열), `Vec<T>`(동적 배열), `&[T]`(슬라이스). 경계 검사 기본 수행.

## 5. 소유권과 대여 검사기 (심장 💓)
1. **소유권 규칙:** 모든 값은 단 하나의 소유자(변수)를 가지며, 스코프를 벗어나면 자동 해제(`Drop`). 이동(Move) 시 원본은 무효화됨.
2. **대여(Borrowing):** 
   * 불변 참조(`&T`): 여러 개 공존 가능.
   * 가변 참조(`&mut T`): 오직 하나만 존재 가능 (데이터 경합 원천 차단).
3. **수명(Lifetimes):** 참조가 유효한 기간을 서술하는 장치(`&'a T`). 대부분 컴파일러가 추론함.

## 6. 포인터와 스마트 포인터
* **`Box<T>`:** 단독 소유 힙 포인터 (`std::unique_ptr` 대응).
* **`Rc<T>` / `Arc<T>`:** 공유 소유 (`shared_ptr` 대응). 단일 스레드(`Rc`) / 멀티 스레드(`Arc`).
* **내부 가변성:** `Cell<T>`(Copy 타입), `RefCell<T>`(런타임 대여 검사)를 통해 불변 객체 내부 수정.
* **`Weak<T>`:** 순환 참조 방지를 위한 약한 참조 (`std::weak_ptr` 대응).

## 7. 데이터와 행위의 분리
* **`struct` + `impl`:** 데이터와 메서드를 분리하여 정의. `&self`는 읽기 전용, `&mut self`는 수정 메서드.
* **`enum`:** 단순 정수형을 넘어 다양한 데이터를 담는 상자 (`std::variant`의 상위 호환).
* **`Option<T>`:** `None` / `Some(T)`를 통한 안전한 null 대체 타입.
* **패턴 매칭:** `match`와 `if let`을 통한 강력한 구조 분해 및 완전성 검사.

## 8. 트레이트와 다형성
* **트레이트(Trait):** 상속 대신 "이런 행위를 할 수 있다"는 규격(인터페이스/컨셉트).
* **디스패치:** 제네릭을 통한 정적 디스패치(`impl Trait`, 제네릭)와 `dyn Trait`을 통한 동적 디스패치.
* **클로저:** `Fn`, `FnMut`, `FnOnce` 트레이트를 통해 주변 환경 캡처 방식을 정밀하게 제어.
* **이터레이터:** `map`, `filter`, `collect` 등 지연 평가 체인 제공 (`std::ranges` 대응).

## 9. 표준 트레이트
* **`#[derive(...)]`:** `Debug`, `Clone`, `Copy`, `PartialEq`, `Eq`, `Default` 자동 생성.
* **주요 트레이트:** `Default`(기본값), `Clone`/`Copy`(복사), `Drop`(소멸자), `Deref`(역참조), `From`/`Into`(변환), `Send`/`Sync`(스레드 안전성).

## 10. 모듈 시스템
* **`mod`:** 파일 구조와 1:1로 매핑되는 모듈 트리.
* **접근 제어:** 클래스가 아닌 **모듈** 단위 (`pub`, `pub(crate)` 등 명시).
* **Cargo:** `Cargo.toml`을 통한 단일 의존성 및 패키지 관리.

## 11. 에러 처리
* **`Result<T, E>`:** 복구 가능한 에러를 값으로 반환 (`Ok` / `Err`).
* **`?` 연산자:** 에러 전파를 간결하게 처리.
* **`panic!`:** 복구 불가능한 치명적 상황에서 사용 (`std::terminate` 대응).

## 12. C++ 개발자의 전환 가이드
* 컴파일러의 에러 메시지를 방해가 아닌 가이드로 활용.
* 소유권과 참조 모델을 중심으로 객체 및 데이터 구조 재설계.

## 13. 테스트와 품질 도구
* **단위/통합 테스트:** `#[test]`, `cargo test`를 통한 내장 테스트 워크플로.
* **코드 품질:** `cargo fmt`(포맷팅), `cargo clippy`(린트 및 관용구 진단).

## 14. 동시성 프로그래밍
* **스레드:** `thread::spawn`과 `move` 클로저를 통한 소유권 이동.
* **공유 가변성:** `Arc<Mutex<T>>`를 통한 안전한 스레드 간 상태 공유 및 RAII 락 가드.
* **메시지 전달:** `mpsc` 채널을 활용한 소유권 기반 데이터 전송.

## 15. 비동기 프로그래밍
* **`async`/`await`:** `Future` 트레이트 기반의 비동기 작업 표현 (Tokio 등 런타임 활용).
* C++20 코루틴과의 모델 차이 이해.

## 16. C/C++ 연동과 `unsafe`
* **FFI:** `extern "C"`와 `#[unsafe(no_mangle)]`을 통한 C ABI 호환 함수 내보내기.
* **`unsafe`:** 포인터 역참조 및 외부 계약 수행을 위한 최소한의 신뢰 경계.

## 17. 실무 학습 로드맵
* 1단계(Cargo/문법)부터 9단계(FFI/unsafe)까지 점진적 학습.
* 작은 CLI 프로그램(JSON/CSV 파서 등) 제작을 통한 실무 적용 권장.
